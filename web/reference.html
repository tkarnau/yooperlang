Overview

Yooperlang separates three ideas that other languages tend to conflate: types (what a value is), traits (what it can do), and kinds (how a binding must be used).

Modules & imports

Every .yoop file is a module. Imports use relative paths only.

import { parse, lex } from "./lexer.yoop";
import * as lex        from "./lexer.yoop";
import { parse as p }  from "./ast.yoop";
import "./init.yoop";                    // side-effect only

Generics

    first: A,
    second: B,
}

function swap<A, B>(p: Pair<A, B>): Pair<B, A> {
    return { first: p.second, second: p.first };

Fallible values & ?

Any enum with Ok / Err variants is fallible. The ? operator propagates the Err payload through callers of the same enum shape.
