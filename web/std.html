two import rules that catch everyone

Values from std/ must be namespaced. import * as vec from "std/core/vec.yoop"; then vec.vecNew(8). A named import of a function or const is a hard error, because a short name like info or error would shadow user identifiers in every module that touched the library. Types, traits, kinds, enums and variants are exempt and may be imported by name.

Import the module, never a file inside it. A path with no .yoop on the end is a directory module whose files share one namespace: from "std/http", never from "std/http/server.yoop".
